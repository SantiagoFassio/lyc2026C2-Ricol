# lyc2026C2-Ricol

Trabajo práctico de creación de lenguaje para La materia de lenguajes y compiladores.

## Sintaxis de Ricol

### Comentarios

```ricol
@ Esto es un comentario. Este sera ignorado al escanear
```

### Operaciones matematicas

```ricol
1 + 2;
2 * 3 - 5;
2 * (3 + 5);
10 / 3;  @ División flotante (=3.3333)
10 // 3;  @ División entera (=3)
3 % 2;  @ Resto (=1)
-(-95); @ =95

@ Quizás lo agregamos
2 ** 4; @ Potencia
```
